ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА

1. Требования
Для работы с проектом рекомендуется использовать:
- Python 3.14.5
- Git
- PyCharm или другую IDE с поддержкой Python
Проверить установленную версию Python в Windows можно командой:
py -3.14 --version

Ожидаемый результат:
Python 3.14.5

Если Python 3.14 не установлен, его необходимо установить перед продолжением.

2. Клонирование репозитория
Склонируйте репозиторий:
git clone <URL_РЕПОЗИТОРИЯ>
Перейдите в папку проекта:
cd SiriusChampionsDTtoy

3. Создание виртуального окружения
Для проекта рекомендуется использовать отдельное виртуальное окружение .venv.
Создайте его на Python 3.14:
py -3.14 -m venv .venv
Активируйте окружение:
.\.venv\Scripts\Activate.ps1

После активации в начале строки терминала должно появиться:
(.venv)
Например:
(.venv) PS C:\...\SiriusChampionsDTtoy>

Проверьте версию Python:
python --version
Ожидаемый результат:
Python 3.14.5

4. Установка зависимостей
Все необходимые Python-пакеты перечислены в файле:
requirements.txt
Установите их командой:
python -m pip install -r requirements.txt
Вместе с остальными зависимостями будет установлен пакет REPEAT, находящийся в папке проекта:
packages/


5. Настройка PyCharm
Если используется PyCharm, необходимо выбрать созданное виртуальное окружение в качестве интерпретатора проекта.
В настройках проекта выберите Python Interpreter:
<путь к проекту>\.venv\Scripts\python.exe
После этого весь код проекта будет запускаться с установленными зависимостями.


6. Если виртуальное окружение уже создано
При следующем запуске проекта повторно создавать .venv и устанавливать все пакеты не нужно.
